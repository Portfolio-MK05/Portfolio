# NordicGear

Fikcyjny sklep internetowy z elektroniką i sprzętem komputerowym. Projekt portfolio w czystym HTML, CSS i JavaScript, bez frameworków.

## Funkcje
- responsywny układ i menu mobilne
- wyszukiwarka, filtrowanie po kategorii i cenie, sortowanie
- koszyk z licznikiem, zmianą ilości i zapisem w localStorage
- karta produktu w oknie modalnym
- formularz kontaktowy z walidacją
- tryb jasny i ciemny (domyślnie wg ustawień systemu)

## Struktura
```
index.html
css/style.css
js/data.js   # produkty
js/app.js    # logika sklepu
img          # zdjęcia produktów
```
